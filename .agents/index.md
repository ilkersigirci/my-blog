# Agent Guide

This repository is a personal blog built with Hugo and the `hugo-narrow`
theme. Content lives under `content/`, Hugo configuration lives in
`config/_default/`, custom frontend assets live in `assets/`, and static files
live in `static/`.

Use this file as the entry point for AI coding agents. The focused guidance
below is split by task area:

- [Hugo](hugo.md): project overview and local development command.
- [Image optimization](image_optimization.md): guidance for AVIF/WebP/JPG
  fallback work using official Hugo image processing documentation.
- [Update hugo-narrow theme](skills/update-hugo-narrow-theme/SKILL.md):
  workflow for pinning the theme submodule to a tag.

For general setup, theme update notes, and Cloudflare Pages build settings, see
the root [README.md](../README.md).
